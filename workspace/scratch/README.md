# scratch — ephemeral thinking

Scripts the agent writes to answer a question, runs, reads, and **deletes**.

Nothing here is durable. Anything left behind is disposable, and the whole
directory is gitignored. If a script turns out to be worth keeping, it does not
belong here — move it into `pipeline/` as a module with a test.

The loop this half belongs to: **think in scratch, remember in notes, report
through lineage.**
